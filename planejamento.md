🟣 Fase 1: Planejamento
- [ ] Definir o que o marketplace faz (C2C, B2C ou B2B?)
- [ ] Levantar requisitos funcionais e não-funcionais
- [ ] Definir arquitetura do sistema
- [ ] Escolher a stack tecnológica (ex: Next.js + Node.js + PostgreSQL)
- [ ] Desenhar o modelo do banco de dados (tabelas: users, products, orders, payments, reviews)
- [ ] Definir os endpoints da API (autenticação, produtos, pedidos, pagamentos)
- [ ] Criar wireframes das telas principais (home, produto, carrinho, checkout, painel admin)

🟢 Fase 2: Execução / Desenvolvimento
- [ ] Configurar repositório Git e ambiente de desenvolvimento (Docker)
- [ ] Criar estrutura do projeto (backend + frontend separados ou monorepo)
- [ ] Implementar autenticação (cadastro, login, JWT)
- [ ] Criar CRUD de produtos (cadastrar, listar, editar, excluir)
- [ ] Implementar busca e filtros de produtos
- [ ] Criar carrinho de compras (adicionar, remover, calcular total)
- [ ] Implementar fluxo de checkout e geração de pedidos
- [ ] Integrar gateway de pagamento (Stripe/Mercado Pago em modo sandbox)
- [ ] Criar sistema de avaliações e reviews
- [ ] Desenvolver painel do vendedor (gerenciar produtos e vendas)
- [ ] Desenvolver painel administrativo (gerenciar usuários e pedidos)
- [ ] Construir as telas do frontend (home, busca, produto, carrinho, checkout, dashboards)
- [ ] Tornar o site responsivo (funcionar bem no mobile)

🟡 Fase 3: Testes
- [ ] Testar manualmente cada funcionalidade (fluxo completo de compra)
- [ ] Testar a API com Postman/Insomnia (todos os endpoints)
- [ ] Testar pagamento no sandbox (cartão aprovado e recusado)
- [ ] Verificar responsividade em diferentes telas
- [ ] Revisar o código (code review próprio ou com colega)

🔴 Fase 4: Deploy
- [ ] Escolher plataforma de hospedagem (Vercel, Railway, Render, AWS)
- [ ] Configurar banco de dados em produção
- [ ] Fazer deploy do backend
- [ ] Fazer deploy do frontend
- [ ] Configurar variáveis de ambiente (chaves de API, URLs, secrets)
- [ ] Testar se tudo funciona no ambiente de produção

🟣 Fase 5: Feedback / Acompanhamento
- [ ] Compartilhar o projeto com amigos/colegas para testar
- [ ] Coletar feedback sobre usabilidade e bugs
- [ ] Corrigir bugs encontrados
- [ ] Anotar ideias de melhorias para versões futuras

⚫ Fase 6: Encerramento
- [ ] Revisar se todas as funcionalidades planejadas foram entregues
- [ ] Escrever README com instruções de instalação e uso
- [ ] Documentar a API (ex: README ou Swagger)
- [ ] Fazer commit final e tag de versão no Git
- [ ] Escrever um resumo do que aprendeu no projeto
